Ex 1. Welford's Recurrence Formulas

Numerically Stable Incremental Variance

Computing the sample variance using the standard two-pass formula or the naive one-pass formula (∑x² - nμ²) can lead to catastrophic cancellation when values are close together. Welford's method calculates the running variance in a single pass with high numerical stability.

1. Knuth's Recurrence for the Mean (μₙ)
μₙ = μₙ₋₁ + (xₙ - μₙ₋₁) / n
2. Derivation of Sum of Squares (Mₙ)
Let Mₙ = ∑(xₖ - μₙ)²
Mₙ - Mₙ₋₁ = (xₙ - μₙ)² + ∑ₖ₁ⁿ⁻₁ [ (xₖ - μₙ)² - (xₖ - μₙ₋₁)² ]
Using μₙ - μₙ₋₁ = (xₙ - μₙ₋₁) / n and expanding the square difference yields the elegant recurrence:
Mₙ = Mₙ₋₁ + (xₙ - μₙ₋₁) · (xₙ - μₙ)
3. Sample Variance (S²)
Sₙ² = Mₙ / (n - 1)

Implementation Logic: The core recurrence is astonishingly compact, updating the mean and sum of squares incrementally in just three lines.

function computeWelford(data) {
    let mean = 0;
    let M2 = 0;

    for (let i = 1; i <= data.length; i++) {
        let x = data[i - 1];
        
        // --- CORE LOGIC (3 Lines) ---
        let delta = x - mean;
        mean += delta / i;
        M2 += delta * (x - mean);
        // ----------------------------
    }
    
    let variance = M2 / (data.length - 1); // Sample variance
    return { mean, variance };
}

Conclusions: Inferential Statistics & Consistency

Unbiased Estimators & Law of Large Numbers

Unbiased Estimators

Across the m hackers, the average of their individual sampling means closely approximates the true population mean μ. Similarly, the average of their sample variances (using the n-1 Bessel correction) precisely approximates the true population variance σ².

This empirically proves that X̄ and S² are unbiased estimators: E[X̄] = μ and E[S²] = σ². This property is crucial in inferential statistics because it guarantees that our estimates do not systematically overestimate or underestimate the true population parameters.

Effects of System Scale (n)

As the number of systems attempted by each hacker (n) increases, the variability (spread) of the sampling means shrinks dramatically. Specifically, the variance of the sample mean is governed by Var(X̄) = σ² / n.

Because the variance collapses to zero as n → ∞, X̄ is a consistent estimator (Weak Law of Large Numbers). A larger sample size provides a geometrically tighter confidence interval around the true metric.
