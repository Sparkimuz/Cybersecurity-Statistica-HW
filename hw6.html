Ex 1. Independence in Probability and in Statistics

Joint = Product of Marginals

Given a bivariate dataset of \(n\) paired observations \((x_k, y_k)\), where \(X\) takes the categories \(a_1,\dots,a_r\) and \(Y\) the categories \(b_1,\dots,b_c\), the contingency table collects the joint absolute frequencies \(n_{ij} = \#\{k : x_k = a_i,\ y_k = b_j\}\). Summing along rows and columns gives the marginal frequencies \(n_{i\cdot} = \sum_j n_{ij}\) and \(n_{\cdot j} = \sum_i n_{ij}\), with \(\sum_{i,j} n_{ij} = n\). The question of this homework is whether knowing the value of \(X\) tells us anything about \(Y\).

Probabilistic Independence

Two events are independent when the occurrence of one does not change the probability of the other:

$$P(A \cap B) = P(A)\,P(B) \iff P(A \mid B) = P(A) \quad (P(B) > 0)$$

Two random variables are independent when every pair of events they generate is independent, i.e. the joint law factorises:

$$F_{X,Y}(x,y) = F_X(x)\,F_Y(y) \quad \forall\, x,y$$

For discrete variables this is \(p_{ij} = P(X=a_i, Y=b_j) = p_{i\cdot}\, p_{\cdot j}\) for all \(i, j\); for continuous ones, \(f_{X,Y}(x,y) = f_X(x) f_Y(y)\).

Statistical (Empirical) Independence

On observed data, \(X\) and \(Y\) are statistically independent if the relative joint frequency equals the product of the relative marginals:

$$\frac{n_{ij}}{n} = \frac{n_{i\cdot}}{n}\cdot\frac{n_{\cdot j}}{n} \iff n_{ij} = \frac{n_{i\cdot}\, n_{\cdot j}}{n}$$

Equivalently, all the conditional distributions are identical and equal to the marginal one:

$$f_{j\mid i} = \frac{n_{ij}}{n_{i\cdot}} = \frac{n_{\cdot j}}{n} \;\;\forall i, \qquad f_{i\mid j} = \frac{n_{ij}}{n_{\cdot j}} = \frac{n_{i\cdot}}{n} \;\;\forall j$$

The empirical frequencies are estimators of the probabilities (by the LLN, see HMWK 03, \(n_{ij}/n \to p_{ij}\)), so exact empirical independence is almost never observed even when the variables are truly independent: we need a test that measures how far we are from it.

Expected Frequencies & Pearson's χ²

Under \(H_0\): "\(X\) and \(Y\) are independent", the expected frequencies are \(\hat n_{ij} = n_{i\cdot}\, n_{\cdot j} / n\). Pearson's statistic adds up the normalised squared discrepancies:

$$\chi^2 = \sum_{i=1}^{r}\sum_{j=1}^{c} \frac{(n_{ij} - \hat n_{ij})^2}{\hat n_{ij}} \;\xrightarrow{d}\; \chi^2_{(r-1)(c-1)}$$

\(\chi^2 = 0\) means perfect empirical independence. The degrees of freedom are \((r-1)(c-1)\): the free cells once both margins are fixed. The approximation is reliable when all \(\hat n_{ij} \ge 5\) (Cochran's rule).

p-value, Decision & Effect Size

The p-value is the probability, under \(H_0\), of a statistic at least as extreme as the observed one. It is the upper tail of the \(\chi^2_\nu\) distribution, which is a regularised incomplete Gamma function (no elementary closed form, just like \(\Phi\) in HMWK 05):

$$p = P(\chi^2_\nu \ge \chi^2_{obs}) = Q\!\left(\tfrac{\nu}{2}, \tfrac{\chi^2_{obs}}{2}\right) = \frac{\Gamma(\nu/2,\ \chi^2_{obs}/2)}{\Gamma(\nu/2)}$$

If \(p < \alpha\) we reject independence. Since \(\chi^2\) grows with \(n\), its size is normalised by Cramér's V \(= \sqrt{\chi^2 / (n \cdot \min(r-1, c-1))} \in [0,1]\), which measures the strength of the association.

Independence ⇒ zero covariance, but not the converse. Covariance only detects linear association. If \(X\) is uniform on \(\{-1, 0, 1\}\) and \(Y = X^2\), then \(\operatorname{Cov}(X,Y) = E[X^3] - E[X]E[X^2] = 0\), yet \(Y\) is a deterministic function of \(X\): \(P(Y=0 \mid X=0) = 1 \ne P(Y=0) = 1/3\). The χ² test works on the whole joint distribution, so it catches this dependence (dataset ⑤ in the analyser below).

Ex 2. Contingency Table Analyser

Frequencies • Expected • χ² • p-value

Every table below is built programmatically from the raw list of observations: the program reads the pairs \((x_k, y_k)\) one by one, discovers the categories, counts the joint occurrences and then derives marginals, conditional distributions, expected counts, χ² and p-value. The main dataset is the Child Smokers dataset from the course material (654 children: age, height, lung capacity FEV, sex, smoking status); a synthetic IDS log generator gives a cybersecurity scenario with tunable dependence, and any CSV can be pasted.

Dataset & Test Settings

Each event draws a protocol from fixed marginals, then an alert level from \(P(Y\mid X=a_i) = (1-\lambda)\,q + \lambda\, r_i\), where \(q\) is a protocol-independent alert profile and \(r_i\) is a protocol-specific one (SSH brute force, DNS tunnelling, SMTP phishing…). With λ = 0 the variables are independent by construction, so the test should reject only about α of the time; increasing λ or N makes the dependence detectable.

Columns with more than 8 distinct numeric values are automatically grouped into quantile classes; everything else is treated as categorical.

Interpretation

Core Implementation

The functions actually running on this page (simplified excerpt). The p-value uses the regularised upper incomplete Gamma \(Q(a,x)\), evaluated with a series for \(x < a+1\) and a Lentz continued fraction otherwise, with \(\ln\Gamma\) from the Lanczos approximation.

// 1. Contingency table from raw pairs (x_k, y_k)
function buildContingency(xs, ys, rowOrder, colOrder) {
  const rows = rowOrder ?? uniqueInOrder(xs), cols = colOrder ?? uniqueInOrder(ys);
  const ri = new Map(rows.map((v, i) => [v, i])), ci = new Map(cols.map((v, j) => [v, j]));
  const O = rows.map(() => cols.map(() => 0));
  for (let k = 0; k < xs.length; k++) O[ri.get(xs[k])][ci.get(ys[k])]++;   // n_ij
  const rowTot = O.map(r => sum(r));                                    // n_i.
  const colTot = cols.map((_, j) => sum(O.map(r => r[j])));            // n_.j
  return { rows, cols, O, rowTot, colTot, n: sum(rowTot) };
}

// 2. Frequencies, expected counts, chi-square, p-value, Cramer's V
function analyse(T) {
  const { O, rowTot, colTot, n } = T, r = O.length, c = O[0].length;
  const rel     = O.map(row => row.map(v => v / n));                        // f_ij
  const condYX  = O.map((row, i) => row.map(v => v / rowTot[i]));          // f(j | i)
  const condXY  = O.map(row => row.map((v, j) => v / colTot[j]));          // f(i | j)
  const E       = rowTot.map(ri => colTot.map(cj => ri * cj / n));         // n_i. n_.j / n
  let chi2 = 0;
  for (let i = 0; i < r; i++) for (let j = 0; j < c; j++)
    chi2 += (O[i][j] - E[i][j]) ** 2 / E[i][j];
  const df = (r - 1) * (c - 1);
  const pValue = gammaQ(df / 2, chi2 / 2);                                 // upper tail of chi2_df
  const cramerV = Math.sqrt(chi2 / (n * Math.min(r - 1, c - 1)));
  return { rel, condYX, condXY, E, chi2, df, pValue, cramerV };
}

Ex 3. Monte Carlo Check of the χ² Approximation

Simulating H0 with the Observed Margins

The p-value above relies on Pearson's asymptotic result. To verify it, we simulate the null hypothesis directly: we generate \(M\) synthetic datasets of the same size \(n\) in which \(X\) and \(Y\) are drawn independently from the observed marginals \(\hat p_{i\cdot} = n_{i\cdot}/n\) and \(\hat p_{\cdot j} = n_{\cdot j}/n\), and recompute \(\chi^2\) for each one. The histogram of the simulated statistics should overlap the \(\chi^2_\nu\) density, the share of simulated values above the critical value should be close to α (empirical type-I error) and the share above the observed value is a Monte Carlo p-value that does not depend on the asymptotic approximation (useful when some \(\hat n_{ij} < 5\)).

Ex 4. Interpretation: Association Is Not Causation

Confounding • Simpson-type Reversal

Results on the Child Smokers dataset

Pair (X, Y)Tableχ²dfp-valueCramér's VConclusion at α = 0.05

① Sex × Smoking: borderline

Not rejecting \(H_0\) is not a proof of independence: it only says that, with 654 children and only 65 smokers, the observed gap between the conditional distributions is compatible with sampling noise. The test has limited power for a small effect; with α = 0.10, or with a larger sample showing the same proportions, the conclusion would change.

② Age × Smoking: strong dependence

Age classes 13–15 and 16–19 are merged into 13–19 so that every expected count is ≥ 5 and Cochran's condition holds. The conditional distribution of smoking changes dramatically across classes, so the variables are clearly dependent.

③ Smoking × FEV: the causality trap

Read naively, this would suggest that smoking improves lung capacity. The explanation is a confounder: age. Older children both smoke more and have larger lungs, because FEV grows with body size.

What the χ² test can and cannot say

  • It answers one question: is the joint distribution different from the product of the marginals? It is symmetric in \(X\) and \(Y\), so it carries no notion of direction ("X causes Y" and "Y causes X" give the same statistic).
  • A small p-value means association (statistical dependence); Cramér's V says how strong it is. A large p-value means "no evidence of dependence", not "independence proven".
  • With huge \(n\) (e.g. millions of log lines) even negligible dependencies become "significant": always look at V and at the conditional profiles, not only at p.

Why association ≠ causation

  • Confounding: a third variable \(Z\) drives both (age → smoking, age → FEV). Formally, \(X \not\perp Y\) but \(X \perp Y \mid Z\) is possible, and vice versa.
  • Reverse causation: \(Y\) may cause \(X\); the test cannot tell the direction.
  • Selection bias: the way units enter the sample can create dependence between independent variables (Berkson's paradox).
  • Chance / multiple testing: testing many pairs at α = 0.05 yields about 5% false discoveries.

The same trap in cybersecurity

  • Hosts with an EDR agent show more detected infections: the agent does not cause malware, it reveals it (measurement / reverse causation).
  • Servers patched most often suffer more attacks: they are the internet-facing ones, so exposure confounds patching and attacks.
  • In the IDS dataset, protocol and alert level are dependent because SSH attracts brute force; this does not mean that "using SSH" makes a connection malicious.

What it takes to claim causality

  • Randomised experiments (A/B tests, controlled red-team exercises): randomisation makes the treatment independent of every confounder.
  • Adjustment for confounders (stratification as above, regression, matching), guided by a causal model of the domain.
  • Supporting criteria (Bradford Hill): temporal precedence, dose-response, consistency across studies, plausible mechanism.
Conclusion. Statistical independence is the factorisation of the joint distribution into its marginals, which on data means that the conditional profiles coincide with the marginal one. Pearson's χ² measures the distance from this situation and the p-value tells whether that distance is larger than sampling noise would produce. On the Child Smokers data, sex and smoking are only borderline associated, while age and smoking, and smoking and FEV, are clearly dependent. The last association is real, but it goes in the opposite direction to the causal effect: within age classes where smoking is common, smokers have lower lung capacity. Dependence detected by a test is a starting point for causal reasoning, not its conclusion.
