Ex 1. Riemann vs Lebesgue Numerical Integration

Domain Partitioning vs Range Partitioning

Classical Riemann integration partitions the domain \([a, b]\) into subintervals \(\Delta x_i\) and sums vertical rectangles \(f(x_i^*)\Delta x_i\). In contrast, Lebesgue integration partitions the range (value set of \(f\)) into subintervals \([y_j, y_{j+1})\) and computes the total measure (length/volume) of their preimages in the domain: \(\int f \, d\mu \approx \sum y_j \cdot \mu(\{x \in [a,b] \mid y_j \le f(x) < y_{j+1}\})\).

Riemann Definition (Domain Partition)

Partition domain \([a, b]\) into \(N\) subintervals: $$\int_a^b f(x)\,dx = \lim_{N \to \infty} \sum_{i=1}^N f(x_i^*) \Delta x$$ Requires function continuity almost everywhere. Fails on highly discontinuous / dense sets (e.g., Dirichlet function).

Lebesgue Definition (Range Partition)

Partition image range \([y_{\min}, y_{\max}]\) into \(M\) slices \([y_j, y_{j+1})\): $$\int_E f\,d\mu = \lim_{M \to \infty} \sum_{j=0}^{M-1} y_j \cdot \mu(E_j), \quad E_j = f^{-1}([y_j, y_{j+1}))$$ Measures set size \(\mu(E_j)\). Handles unbounded & pathological functions cleanly.

Ex 2. Numerical Computation of the Normal CDF

Liouville's Theorem, Error Function & Quadratures

The Cumulative Distribution Function (CDF) of the standard normal distribution \(\mathcal{N}(0, 1)\) is defined as: $$\Phi(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^x e^{-\frac{t^2}{2}} \, dt = \frac{1}{2} \left[ 1 + \text{erf}\left( \frac{x}{\sqrt{2}} \right) \right]$$

Liouville's Theorem & Non-Elementarity

By Liouville's Theorem in differential algebra, an elementary antiderivative of \(f(z) e^{g(z)}\) exists if and only if it can be written as \(h(z) e^{g(z)}\) for some elementary function \(h(z)\).

For \(e^{-t^2/2}\), no such elementary function \(h(t)\) exists. Hence, \(\Phi(x)\) cannot be expressed using standard elementary functions (polynomials, trig, exponentials, logs) and necessitates special functions like \(\text{erf}(x)\) or numerical integration.

Numerical Approximation Methods

Because real-time software cannot evaluate infinite integrals directly, we employ 3 primary numerical paradigms:

  • 1. Numerical Quadrature: Simpson's Rule / Gauss-Legendre on finite truncated interval \([-8, x]\).
  • 2. Power Series Expansion: Maclaurin expansion of \(\text{erf}(z) = \frac{2}{\sqrt{\pi}} \sum_{k=0}^\infty \frac{(-1)^k z^{2k+1}}{k! (2k+1)}\).
  • 3. Rational Approximation: High-precision Cody / Abramowitz & Stegun rational polynomials (accurate to \(10^{-15}\)).
